## 🗂️ Repository Structure

| 📁 Path | 🎯 What It Is |
|---------|--------------|
| `app/` | 🖥️ **Desktop App** — Tauri + Rust + React (native installers) |
| `web/` | 🌐 **Web App** — `web/frontend` (React+Vite) + `web/backend` (Rust Actix-web) |
| `web-server/` | 📦 **All-in-One** — backend + frontend in one binary (Docker/Render/Vercel) |
| `ai_proxy.py` | 🤖 **AI Helper** — standalone Flask proxy to Google Gemini |
| `screenshots/` | 📸 UI screenshots |
| `.github/workflows/` | ⚙️ CI/CD workflows |
